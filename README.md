# C++ Open-Ended Experiments

## About the Repository

This repository contains **15 C++ Open-Ended Experiments** developed as part of academic coursework. These experiments demonstrate the practical implementation of fundamental and advanced C++ programming concepts through problem-solving and real-world application scenarios.

The programs cover a variety of topics, including object-oriented programming, generic programming, sorting techniques, mathematical operations, exception handling, and application-oriented system development.

Each experiment focuses on applying programming logic to solve a specific problem while improving code organization, reusability, efficiency, and understanding of C++ concepts.

## How to Execute the Programs

**Step 1:** Clone the repository.

```bash
git clone https://github.com/nishanth-28-hub/OWC_CCA_Open_Ended.git
```

**Step 2:** Navigate to the project directory.

```bash
cd OWC_CCA_Open_Ended
```

**Step 3:** Compile any experiment.

```bash
g++ 01_shape_area.cpp -o output
```

**Step 4:** Execute the compiled program.

```bash
./output
```

For Windows:

```bash
output.exe
```

Replace the filename with the required experiment's source file to execute another program.
